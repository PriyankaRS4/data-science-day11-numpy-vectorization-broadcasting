# NumPy Vectorization and Broadcasting

## Task 11

This project demonstrates **NumPy Vectorization and Broadcasting** using the **Iris Dataset**.

## Objective

To perform arithmetic operations on complete NumPy arrays and understand broadcasting between arrays of compatible shapes without using unnecessary Python loops.

## Concepts Covered

- Vectorized arithmetic operations
- Scalar broadcasting
- Broadcasting with 1D and 2D arrays
- Feature-wise calculations
- Mean centering
- Loop-based vs vectorized computation
- Performance comparison

## Technologies Used

- Python
- NumPy
- Jupyter Notebook
- Iris Dataset

## Files

- `task11_numpy_vectorization_broadcasting.ipynb` — Main Jupyter Notebook
- `iris.csv` — Dataset
- `requirements.txt` — Required Python package
- `README.md` — Project documentation

## Dataset

The Iris dataset contains four numerical features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Key Learning

Vectorization allows operations to be performed on complete NumPy arrays instead of processing each element with explicit Python loops.

Broadcasting allows NumPy to perform arithmetic operations between arrays of different but compatible shapes.

These techniques make numerical computation cleaner, faster, and more efficient.

## How to Run

1. Clone or download this repository.
2. Install the required package:

```bash
pip install -r requirements.txt
```

3. Open the notebook:

```bash
jupyter notebook task11_numpy_vectorization_broadcasting.ipynb
```

4. Run all cells.
